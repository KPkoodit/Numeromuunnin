## Numeromuunnin

Tämä ohjelma kääntää roomalaiset numerot länsimaalaisiksi numeroiksi. Syötteenä hyväksytään merkit I, X, V, L, C, D ja M. Lisäksi tarkastetaan, että syöte seuraa roomalaisten numeroiden oikeinkirjoitussääntöjä. Ohjelman voi sammuttaa painamalla Q.

## Käynnistys

Ohjelmaa voi testata komentoriviltä.

<ol>
    <li>Lataa projekti koneellesi.</li>
    <li>Navigoi kansioon, jossa on App.java-tiedosto.</li>
    <li>Kirjoita komentoriville: `javac App.java`. Komento kääntää koodin.</li>
    <li>Kirjoita komentoriville: `java App`. Komento avaa ohjelman.</li>
</ol>
